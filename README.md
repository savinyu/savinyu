## 🚀 Featured Projects

### 🎥 [Meet](https://github.com/savinyu/Meet)

A real-time video communication application built around **native WebRTC**.

**Tech:** React · TypeScript · Vite · Node.js · Express · WebSocket · WebRTC

Highlights:

- Peer-to-peer audio and video communication
- WebSocket-based signaling
- SDP offer/answer negotiation
- ICE candidate exchange
- STUN/TURN support
- Screen sharing
- Camera and microphone controls
- Room and peer management
- Media-state synchronization

This project helped me understand real-time communication at a deeper level, rather than relying on a third-party video calling SDK.
